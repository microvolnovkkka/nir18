## Реализовано — 2.3.2, часть 1

- Использован существующий локальный Git в папке НИР; документы не перемещались. Созданы `frontend/`, `backend/`, `scripts/`, Compose, README и пример окружения.
- React/TS/Vite: минимальная техническая страница, проверяющая готовность API. Рабочих страниц продукта ещё нет.
- Go/net/http: pgxpool, graceful shutdown, только `/api/health/live` и `/api/health/ready`.
- Две SQL-миграции: полная проектная схема и начальные 5 аккаунтов/5 направлений/15 подтем. Аккаунты неактивны, паролей нет. Runner встраивает SQL, проверяет checksum и применяет транзакционно под advisory lock.
- Compose: PostgreSQL → migrate → API → Caddy/React. Постоянные тома БД и media. Случайный локальный пароль только в игнорируемом `.env`.
- Внутренний `bot.Responder`, явно обозначенная заглушка без сети и тесты. 07.11.2026 получены и проверены реальный Go-модуль DeepSeek, консольная проверка и отдельный локальный стенд. HTTP бота ещё не подключён до авторизации; наличие модуля не означает его интеграцию в основной сайт.
- Создан публичный [GitHub microvolnovkkka/nir18](https://github.com/microvolnovkkka/nir18). После отдельного подтверждения пользователя опубликован полный пакет из 49 файлов в ветке `codex/foundation`, базовый коммит `adbd99e` (проектирование и проверенный каркас). Удалённая ветка сверена с локальным Git. Последующий коммит обновляет только этот статус. Приглашений участникам на запись нет, их GitHub-аккаунты пока не предоставлены; публичное чтение доступно.
