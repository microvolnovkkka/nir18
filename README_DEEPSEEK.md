# DeepSeek Flash: локальная проверка статей

Локальный стенд разработчика бота для проекта НИР18. Замеры живого прогона собраны в [отчёте](docs/stages/02-foundation/DEEPSEEK_TEST_REPORT.md).

## Быстро открыть на Windows

1. Дважды щёлкните `START-DEEPSEEK.cmd` в корне этой папки.
2. Когда появится приглашение, вставьте ключ официального API DeepSeek. Ввод видимый. Ключ не записывается в файл.
3. Откроется **http://127.0.0.1:8090**. Адрес **http://localhost:8090** также работает на обычной конфигурации loopback.
4. Нажмите «Обзор» либо вставьте свои материалы, затем «Подготовить ответ».
5. Для остановки используйте `STOP-DEEPSEEK.cmd`.

Каждая отправка выполняет платный запрос к API. В стенде нет автоматических повторов. Доступны обычный режим Flash и режим с рассуждением. Системный промпт подключается автоматически из `backend/internal/bot/prompt.txt`; вставлять его в поле заметок не требуется.

При первом запуске нужны интернет для зависимостей и Go >=1.26.1. На подготовленном компьютере Windows расположение уже установленного Go записано отдельно от исходников. На другом компьютере установите Go с https://go.dev/dl/ либо задайте `NIR18_GO` — полный путь к `go.exe`.

Скрипт каждый раз собирает актуальные исходники. Если стенд уже работает, он открывает существующую страницу; после изменения кода или ключа сначала остановите его. Если порт занят чужим процессом, он не останавливается автоматически. Другой порт:

```powershell
.\START-DEEPSEEK.cmd -Port 8091
```

## Файлы модуля

- `backend/internal/bot` содержит клиент DeepSeek, системный промпт и проверки Markdown.
- `backend/cmd/bot-playground` запускает локальный стенд, а `backend/cmd/deepseek-check` выполняет консольную проверку.
- `.env.example` описывает настройки. Перед запуском передайте их как переменные окружения. На Windows скрипт запрашивает ключ, если он ещё не задан.

Рабочие файлы стенда на Windows хранятся в `Документы\Codex\nir18-deepseek-runtime\projects\<идентификатор-папки>`.


## Запуск из терминала на любой поддерживаемой Go системе

Из корня полноценного проекта или этого самостоятельного пакета:

```powershell
$env:DEEPSEEK_API_KEY = Read-Host 'Ключ DeepSeek'
cd backend
go run ./cmd/bot-playground
```

На Linux/macOS задайте `DEEPSEEK_API_KEY` средствами своей оболочки и выполните ту же команду Go из `backend`. Системная инструкция встроена в бинарник; отдельная сборка React не требуется. PostgreSQL, Docker и основной сайт не нужны для этого тестового стенда.

Консольная проверка вместо браузера:

```text
go run ./cmd/deepseek-check
go run ./cmd/deepseek-check -thinking=true
go run ./cmd/deepseek-check -topic "Геометрические признаки" -message "Подготовь теоретический обзор; экспериментов не было" -markdown my-draft.md
```

Путь `-markdown` задаётся относительно текущей папки. Содержимое файла отправляется модели как текущий текст редактора. Ключи не передавайте флагами командной строки.

## Что показывает стенд

- Проверенный `report` с Markdown либо `clarification` с уточняющим вопросом.
- JSON ответа и безопасные измерения: модель, полный elapsed_ms, HTTP поставщика, finish_reason, токены при наличии.
- Только наличие и число символов `reasoning_content`; сам текст рассуждений не передаётся браузеру.
- Ошибки доступа/баланса/сети, лимита, дедлайна, структуры ответа и несовпадения изображений.

Вывод Markdown показан как безопасный текст, без выполнения HTML и без загрузки картинок по ссылкам. Это проверка ответа и исходной разметки; окончательный рендерер формул/Markdown основного сайта — отдельная часть проекта.

«Скопировать Markdown» и «Скачать .md» доступны для ручной работы. Ответ не заменяет текст редактора автоматически, не публикуется и не сохраняется на сервере. История и материалы находятся в памяти вкладки; после перезагрузки страницы теряются.

Рассуждения могут занять часть лимита токенов и времени. Если ответ оборван, пуст либо JSON неверен, результат блокируется. По умолчанию модуль отправляет `max_tokens=32768`. Задать меньший предел в диапазоне 256–32768 можно через `DEEPSEEK_MAX_TOKENS` до запуска процесса. На ответ отводится до 90 секунд.

## Проверки без расходов на API

Из `backend`:

```text
go test ./...
go vet ./...
go build ./cmd/bot-playground ./cmd/deepseek-check
```

Автоматические тесты используют `httptest.Server` и фиктивные ответы. Настоящий ключ им не нужен, платные запросы не выполняются. Для `go test -race ./internal/bot ./internal/botplayground` дополнительно нужен настроенный C-компилятор.

Подробности границ и подключения — [DEEPSEEK_LOCAL.md](docs/stages/02-foundation/DEEPSEEK_LOCAL.md). Материалы для ручной приёмки — [deepseek-test-cases.md](docs/stages/02-foundation/deepseek-test-cases.md).
