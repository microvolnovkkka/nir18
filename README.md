# nir18 — научный блог НИР

React + TypeScript + Vite, Go/net/http + pgx, PostgreSQL, Caddy и Docker Compose. Сейчас готов каркас **2.3.2, часть 1**: проверка сервера/БД и миграции. Вход, права, предметный API и рабочий интерфейс ещё не реализованы. Реальная модель не подключена; внутренний тестовый Responder обозначен заглушкой.

## Быстрый локальный запуск

Нужны Docker Engine/Desktop с Compose и Git. Команды из корня проекта в macOS/Linux/Git Bash:

```sh
git clone https://github.com/microvolnovkkka/nir18.git
cd nir18
./scripts/init-env.sh
docker compose up -d --build
```

Скрипт создаст `.env` со случайным локальным паролем БД (требуется openssl). Если openssl отсутствует, скопируйте `.env.example` в `.env` и замените пароль случайной строкой **hex**; не публикуйте `.env`. Миграции выполняются автоматически перед API.

Открыть [localhost:8080](http://localhost:8080). Проверка:

```sh
./scripts/check-local.sh
docker compose ps -a
```

Ожидается `status: ready`, успешная SQL-проверка; `migrate` завершается с кодом 0 — это нормально. Пять аккаунтов созданы без паролей и неактивны до следующей карточки. SQL-проверка рассчитана на этот начальный этап.

Остановить с сохранением данных:

```sh
docker compose down
```

**Не добавляйте `-v`**, если хотите сохранить данные томов. После изменений SQL/Go сначала пересоберите образ; подробный порядок миграций и диагностика — ниже.
